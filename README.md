# Dailydle

A daily puzzle game where you defeat a series of games in order. The puzzles reset every day.

## How it works

- Daily reset: the game seed is derived from today's date, so the puzzles change each day and are the same for everyone.
- Progression: games are played in sequence, so you must clear each one to unlock the next.
- Current games:
  - **Sudoku** (6×6) — select a cell, then fill it with a number (1–6). Keyboard shortcuts: press `1`–`6` to fill the selected cell, `Backspace`/`Delete` to clear it.
