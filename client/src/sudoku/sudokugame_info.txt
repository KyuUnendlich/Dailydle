Sudoku Rules
------------
Sudoku is a logic-based number placement puzzle.

Goal
----
Fill a 9x9 grid with digits so that each column, each row, and each of the nine 3x3 sub-grids contain all of the digits from 1 to 9.

Rules
-----
1. Each row must contain all digits 1-9 exactly once.
2. Each column must contain all digits 1-9 exactly once.
3. Each 3x3 box must contain all digits 1-9 exactly once.
4. Some cells are pre-filled as clues; these cannot be changed.
5. The puzzle must have exactly one unique solution.

Notation
--------
- Pre-filled clue cells: given numbers (cannot be modified)
- Empty cells: to be filled by the player
- Correctly filled cells: match the unique solution
